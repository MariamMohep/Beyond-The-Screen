# 📊 Social Media & Productivity Analysis

## 📌 Project Overview

This project analyzes the relationship between social media usage and productivity-related behaviors.

The analysis focuses on how social media habits may be associated with productivity, attention span, deep-work duration, task completion, and productivity decline.

The project uses data analysis and visualization techniques to transform raw data into meaningful insights through Python, SQL Server, and Power BI.

---

## 🎯 Project Objectives

- Analyze social media usage patterns.
- Examine productivity levels and productivity decline.
- Explore attention span and deep-work duration.
- Analyze task completion patterns.
- Investigate the relationship between social media habits and productivity.
- Build an interactive Power BI dashboard to present the findings.

---

## 📂 Dataset

The dataset contains information about **300 participants** and covers several aspects related to:

- Social media usage
- Screen time
- Productivity
- Cognitive performance
- Social media habits
- Demographics
- Mental and behavioral factors

The dataset was structured into five related tables:

1. `Fact_User_Metrics`
2. `Participant`
3. `SocialMedia_Habits`
4. `Productivity_Cognition`
5. `Mental_Detox`
